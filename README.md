# termiinal

Десктоп-терминал для Windows со встроенным ИИ-наставником — название из «терминал» + «ИИ».
Подключаешься по SSH к удалённой машине или открываешь локальный Git Bash, работаешь как в
обычном терминале, а агент (Claude) всё это время видит, что происходит, и подсказывает —
но сам ничего не выполняет: каждую команду вводишь и жмёшь Enter ты сам.

## Что он умеет

- **Подключения как в PuTTY.** Список сохранённых пресетов + форма нового подключения
  (пользователь/хост/порт/ключ, ключ — через системный проводник). Маленькое окно для выбора
  подключения само разворачивается в рабочий размер, когда сессия поднимается, и сжимается
  обратно при отключении.
- **Агент видит блоки, не весь экран.** Шелл-интеграция (OSC 133/633) нарезает вывод на блоки
  «команда → вывод → код возврата» — агенту уходит именно это, а не сырой текст терминала с
  переносами прогресс-баров и ANSI-мусором.
- **Чат с агентом** рядом с терминалом: обсуждаешь задачу, агент ведёт план (чек-лист шагов,
  обновляется по ходу разбора) и предлагает следующую команду — текстом, не выполняя её.
- **Хоткей «Глянь»** — форсирует разбор последнего блока (или живой снимок ещё выполняющейся
  команды) в обход политики, когда не хочешь ждать.
- **Подсветка опасных команд при вставке** (`rm -rf`, `dd`, `curl … | sh` и т.п.) — вставка
  требует явного подтверждения, а не проходит молча.
- **Затирание секретов** перед отправкой агенту — пароли, токены, приватные ключи вырезаются
  из текста блоков и чата.
- **Гибкая раскладка.** Терминал, чат, план и лог блоков — отдельные панели, каждая
  прячется/показывается своей кнопкой и подстраивается под размер окна; показаны все сразу —
  получается что-то вроде сплит-режима, без отдельного переключателя.
- **Само обновляется** — проверяет новые версии на GitHub Releases, ставит в один клик.

Подробное техническое задание — в [docs/tz.md](docs/tz.md), что сделано на каждом этапе — в
`docs/stage*.md`.

## Что нужно, чтобы это работало

- **Windows** (использует ConPTY, `ssh.exe`, Git Bash — другие платформы не поддерживаются).
- **[Claude Code](https://claude.com/claude-code) CLI**, установленный и залогиненный в свою
  подписку — программа запускает `claude -p` от твоего же аккаунта, не хранит и не передаёт
  токены, не проксирует запросы через чужую учётку. Без него агент просто не запустится.
- Для SSH-подключений — уже настроенный ключ на машине, к которой подключаешься (сама программа
  ключи не генерирует).
- Для локального Git Bash — установленный [Git для Windows](https://git-scm.com/download/win)
  (путь к `bash.exe` ожидается стандартный, `C:\Program Files\Git\bin\bash.exe`).

Первый запуск нестандартно собранного `.exe` на чужой машине почти наверняка покажет
предупреждение Windows SmartScreen («Защитник Windows не пропустил неопознанное приложение») —
это из-за отсутствия платной подписи кода, а не баг. Жми «Подробнее» → «Выполнить в любом случае».

## Разработка

Используемый стек: Tauri (Rust) + xterm.js/`@xterm/headless` + `portable-pty` (ConPTY) +
`ssh.exe`. Скаффолд создан через `npm create tauri-app@latest` (шаблон `vanilla-ts`).

```powershell
npm install
npm run tauri dev   # запуск в разработке
npm test            # vitest
```

Автообновление, подпись релизов и выпуск новой версии через GitHub Actions —
[docs/stage5.md](docs/stage5.md).
