# Этап 1 — прототип рисков

Цель: до постройки UI убедиться, что нарезка блоков вообще может работать на Windows через ConPTY.
Если что-то из этого не работает, вся архитектура «блоков» из ТЗ требует пересмотра ещё до того,
как вложен труд в интерфейс.

## Что проверяем

- [ ] **OSC-маркеры доходят целыми.** Внедряем в `PS1`/`PROMPT_COMMAND` на тестовой Linux-машине
      (или локально в WSL/через ssh) OSC 133 A/B/C/D и OSC 633 E, читаем сырой поток из
      `portable-pty` в Rust, прогоняем через `@xterm/headless`, проверяем, что маркеры не порезаны
      и не переставлены ConPTY.
- [ ] **Текст команды совпадает с реально выполненной.** Набираем команду с Tab-дополнением и
      правкой строки, затем стрелкой вверх достаём из истории и меняем часть — сверяем, что
      `OSC 633 E` даёт именно финальный текст, а не то, что было напечатано посимвольно.
- [ ] **Внедряемая строка не остаётся в истории.** После впечатывания хук-строки проверяем
      `history` в сессии — строки с хуком там быть не должно (самоудаление через `history -d`).
- [ ] **Headless-рендер даёт чистый текст.** Прогоняем вывод `apt install` и `docker pull`
      (прогресс-бары, `\r`, перерисовки) через `@xterm/headless` и проверяем, что на выходе —
      финальный текст экрана без мусора от промежуточных перерисовок.
- [ ] **Риск ConPTY с печатаемым маркером.** Если OSC всё же бьются, проверить резервный вариант:
      уникальная печатаемая строка-маркер в `PS1`, которую приложение вырезает перед отрисовкой.

## Инфраструктура этапа

- Tauri-проект с минимальным Rust-бэкендом: `portable-pty` поднимает ConPTY, запускает `ssh.exe`
  (или локальный `cmd`/WSL для первых тестов), поток байт идёт во фронтенд через Tauri event.
- Фронтенд: `xterm.js` для отображения + `@xterm/headless` для теневого рендера блока агенту.
- Тестовая цель для ssh — Debian-машина с bash (нужен отдельный тестовый хост или контейнер, не
  связанный с другими проектами).

## Среда разработки

Установлено через winget с правами администратора 2026-10-20: Git, Node.js LTS,
Visual Studio Build Tools (workload VCTools, для MSVC-линковки Rust), rustup (toolchain
`stable-x86_64-pc-windows-msvc`, активен по умолчанию).

Скаффолд: `npm create tauri-app@latest` — шаблон `vanilla-ts`, менеджер `npm`,
identifier `com.pakochka.terminalmentor`.
